## 1. Label (open question #1 from `docs/02`, resolved)

**1D horizon, θ = 1%** — the option recommended in `03_eda.ipynb` item 11.

| | |
|---|---|
| Rule | UP if forward log return > +1%, DOWN if < −1%, FLAT otherwise |
| Class balance | ≈ 30% down / 38% flat / 33% up on the model-ready rows |
| Why not 4h/θ=0.5% | 1D's typical move is ≈7× the round-trip fee vs. ≈2.5× for 4h; fewer samples but a much cleaner signal |

## 2. Features

| Feature | Columns | Rationale (ties back to `docs/02` §4) |
|---|---|---|
| Lagged returns | `ret_lag1,2,3,5,7,14` | Finding 7: weak reversal effect at lag 1 |
| Rolling volatility | `vol_7d, vol_14d, vol_30d` (std of 1D log returns) | Finding 7: strong volatility clustering |
| Average true range | `atr_14` (scaled by close) | Finding 10: range predicts move magnitude |
| Volume signal | `log_volume`, `volume_z` (14d rolling z-score) | Finding 10: volume predicts move magnitude |
| Order-flow | `taker_buy_ratio` | Buy-pressure imbalance; NaN on zero-volume candles |

All features are built from data up to and including `close[t]` only (see the timing convention in
`src/features/returns.py`). `build_features()` drops any row with a NaN feature or label — in practice
the 30-day volatility window is the binding constraint, so the first ~30 rows of the series are dropped.

## 3. Chronological split (open question #2, resolved)

70/15/15 split by position, never shuffled, with the boundary rows purged (`embargo=1`): without this,
the last row of `train` (or `val`) would have a label computed from a close price that falls inside the
next split, leaking outcome information across the boundary.

| Split | Rows | Window |
|---|---|---|
| Train | 2,087 | 2017-10-07 → 2024-04-16 |
| Validation | 446 | 2024-04-18 → 2025-07-07 |
| Test | 448 | 2025-07-09 → 2026-09-29 |

**Test window regime:** buy-and-hold over the test window returns **−25%**, Sharpe **−0.33**, max drawdown
**−53%** — a bear/declining market. Per the business-criterion caveat in `03_eda.ipynb` item 12, a strategy
that sits mostly in cash can beat this buy-and-hold baseline in the final evaluation without being "smart";
the agent's test-window result must be read against this regime, not against the full-period Sharpe of 0.82.

## 4. Start date (open question #3, resolved)

Kept the full 2017-08-17 start. The feature warm-up (30-day volatility window) already trims the thinnest
early rows, and the chronological split pushes 2017–2018 entirely into `train`, where thin liquidity and
the gap-heavy period are least likely to distort evaluation.
