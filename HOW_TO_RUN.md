# How to Run the Project

Bitcoin price prediction with an AI agent that trades a $1,000 paper wallet.
All commands are run from the project root folder `BitcoinPricePrediction`.

> Commands are shown for **Windows PowerShell**. For Git Bash / macOS / Linux, see the notes under each step.

---

## 1. Requirements

- Python **3.11 or newer** (tested with 3.12 and 3.14)
- Git
- Internet access for installing packages and for the **Live** trading mode (everything else works offline)

## 2. Get the code

```powershell
git clone https://github.com/Gaston202/BitcoinPricePrediction.git
cd BitcoinPricePrediction
git checkout marouen
```

Already have the folder? Just open it:

```powershell
cd "C:\Users\Mega Pc\OneDrive - South Mediterranean University\Desktop\DataScience_Lab\BitcoinPricePrediction"
```

## 3. Create and activate a virtual environment

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
```

- If PowerShell blocks the script: `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`, then activate again.
- Git Bash: `source .venv/Scripts/activate` · macOS/Linux: `source .venv/bin/activate`

You should see `(.venv)` at the start of the prompt.

## 4. Install the dependencies

```powershell
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Check it worked:

```powershell
python -c "import pandas, sklearn, fastapi, uvicorn; print('Ready')"
```

## 5. Prepare the data (first time only)

The raw Binance snapshot is already in `data/raw/` - **no download needed**.
The cleaned and model-ready files are generated by the notebooks:

```powershell
jupyter notebook notebooks
```

Run these two notebooks with **Run → Run All Cells**:

| Notebook | Creates |
|---|---|
| `02_data_quality.ipynb` | `data/interim/` - cleaned 1h, 4h and 1D candles |
| `04_feature_engineering.ipynb` | `data/processed/` - train / validation / test feature sets |

Or run them from the terminal without opening Jupyter:

```powershell
jupyter nbconvert --to notebook --execute --inplace notebooks/02_data_quality.ipynb
jupyter nbconvert --to notebook --execute --inplace notebooks/04_feature_engineering.ipynb
```

## 6. Run the admin dashboard and the AI trader

```powershell
python -m dashboard
```

Your browser opens at **http://127.0.0.1:8000** (stop the server with `Ctrl+C`).

| Option | Command |
|---|---|
| Different port | `python -m dashboard --port 8080` |
| Don't open the browser | `python -m dashboard --no-browser` |
| Make it reachable on your network | `python -m dashboard --host 0.0.0.0` |

In the dashboard:

1. **Overview** - all the project charts and model results.
2. **AI Trading** - choose a mode and press **▶ Start AI trading**:
   - **Replay** - the AI trades the unseen test period candle by candle (1 day or 1 hour, adjustable speed).
   - **Live** - the AI trades on the real Bitcoin price from Binance right now (needs internet).
3. **Report figures** - every chart exported by the notebooks.

The first start trains the AI's models (a few seconds) and saves them in `models/`.
To force a retrain, delete the `models/` folder. This is **paper trading only** - no real money, no real orders.

## 7. Run the tests

```powershell
python -m pytest            # whole suite
python -m pytest -q         # short output
python -m pytest tests/test_agent.py tests/test_dashboard.py   # agent + dashboard only
```

`tests/test_dashboard.py` is skipped automatically if step 5 hasn't been done yet.

## 8. Run all the notebooks (full analysis)

Run them in this order (CRISP-DM phases):

| # | Notebook | What it does |
|---|---|---|
| 01 | `01_data_collection.ipynb` | Data source, metadata, data dictionary |
| 02 | `02_data_quality.ipynb` | Gaps, cleaning policy, resampling |
| 03 | `03_eda.ipynb` | Returns, stationarity, autocorrelation, correlations, baselines |
| 04 | `04_feature_engineering.ipynb` | Features, labels, chronological split |
| 05 | `05_modeling.ipynb` | Train and compare classifiers, backtest |
| 06 | `06_evaluation.ipynb` | Check against the success criteria |
| 07 | `07_modeling_iteration.ipynb` | Calibration + bear / bull / range robustness test |
| - | `simulation_demo.ipynb` | Offline $1,000 portfolio simulation |

All at once from the terminal:

```powershell
Get-ChildItem notebooks\0*.ipynb | ForEach-Object { jupyter nbconvert --to notebook --execute --inplace $_.FullName }
```

Git Bash: `for nb in notebooks/0*.ipynb; do jupyter nbconvert --to notebook --execute --inplace "$nb"; done`

## 9. Optional: download fresh data from Binance

Not needed - the repository already contains the frozen snapshot.

```powershell
python -m src.data.collect               # rebuild the snapshot (skips if it exists)
python -m src.data.collect --end now     # fetch up to the latest closed candle
python -m src.data.collect --force       # overwrite the existing snapshot
```

If Binance answers **HTTP 451** (blocked location), use the market-data mirror:

```powershell
$env:BINANCE_USE_DATA_API = "1"
python -m src.data.collect
```

## 10. Troubleshooting

| Problem | Fix |
|---|---|
| `python` is not recognized | Install Python with **Add to PATH**, or use `py -3` |
| `No module named fastapi` / `uvicorn` | Activate `.venv`, then `python -m pip install -r requirements.txt` |
| Dashboard says `...clean.parquet not found` | Run step 5 (notebooks 02 and 04) |
| `Address already in use` | Another program uses port 8000: `python -m dashboard --port 8080` |
| Live mode: "Could not reach Binance" | Check internet / firewall / VPN; Replay mode works offline |
| A notebook can't find `src` | Start Jupyter from the project root, not inside `notebooks/` |
| `The '.style' accessor requires jinja2` | `python -m pip install -r requirements.txt` (jinja2 is now included) |

More detail on every step: [`README_FULL_SETUP.md`](README_FULL_SETUP.md).

# Tools Used

## Language & environment

| Tool | Used for |
|---|---|
| **Python 3.11+** | The whole project: data pipeline, models, agent, web server |
| **venv** | Isolated project environment |
| **pip** + `requirements.txt` | Dependency installation with pinned versions |

## Data collection

| Tool | Used for |
|---|---|
| **Binance REST API** (`/api/v3/klines`, `/api/v3/ticker/price`) | Historical BTC/USDT hourly candles (2017 → 2026) and the live price |
| **data-api.binance.vision** | Binance market-data mirror, fallback when the main API is blocked (HTTP 451) |
| **python-binance** 1.0.37 | Client for downloading the historical snapshot (`src/data/collect.py`) |
| **requests** | HTTP calls for the live price feed (`src/agent/market.py`) |

## Data handling & storage

| Tool | Used for |
|---|---|
| **pandas** 3.0 | Cleaning, gap filling, resampling 1h → 4h → 1D, feature tables |
| **NumPy** 2.5 | Log returns, numeric operations |
| **Apache Parquet** via **PyArrow** 25 | Fast, typed storage for raw / interim / processed data |
| **JSON** | Provenance metadata for the raw snapshot |

## Statistics & machine learning

| Tool | Used for |
|---|---|
| **SciPy** | Distribution tests (normality, fat tails) in the EDA |
| **statsmodels** | Stationarity tests (ADF/KPSS), autocorrelation (ACF/PACF, Ljung-Box) |
| **scikit-learn** 1.9 | Logistic regression, random forest, gradient boosting; macro-F1, ROC-AUC, scaling pipelines |
| **joblib** | Saving and loading the trained agent models (`models/*.joblib`) |

## Visualization & notebooks

| Tool | Used for |
|---|---|
| **Matplotlib** | All report figures in `reports/figures/` |
| **Jupyter Notebook**, **ipykernel** | Interactive analysis, one notebook per CRISP-DM phase |
| **nbconvert**, **nbformat** | Running notebooks from the command line |
| **Jinja2** | Styled result tables (`DataFrame.style`) in the notebooks |

## Trading agent & dashboard

| Tool | Used for |
|---|---|
| **FastAPI** | REST API of the dashboard (`dashboard/app.py`) |
| **Uvicorn** | ASGI web server that runs the dashboard |
| **Pydantic** | Validating the trading settings sent from the browser |
| **Python threading** | Running replay / live trading sessions in the background |
| **HTML / CSS / JavaScript** | Dashboard front end (`dashboard/static/`) |
| **Chart.js** 4.4.4 + **chartjs-adapter-date-fns** 3.0 | Real-time charts; stored in `dashboard/static/vendor/` so it works offline |

## Testing & quality

| Tool | Used for |
|---|---|
| **pytest** | Automated test suite (`tests/`) |
| **httpx** (FastAPI TestClient) | Testing the dashboard API |

## Collaboration & method

| Tool | Used for |
|---|---|
| **Git** + **GitHub** | Version control, team branches (`marouen`, `master`, ...) and pull requests |
| **CRISP-DM** | Project methodology: business understanding → data → preparation → modeling → evaluation |
| **Claude (AI assistant)** | Code review and bug fixes, trading agent and admin dashboard |
